# 阅读清单

目标：用户保存想读的书，更新阅读进度，按状态查看，并导出与当前清单一致的记录。

## 正常要求

- 新增书目后，列表应出现输入的书名，默认状态为未读。
- 标记已读后，该书状态为已读，并计入已读统计。
- 筛选已读时，只显示已读书目；切回全部后，所有书目仍存在。
- 刷新页面后，已经保存的书目和阅读状态仍保留。
- 导出的 JSON 应包含当前所有书目及各自的阅读状态，与界面和本次操作一致。
- 使用说明独立可访问，说明书目保存在当前浏览器。

## 入口

`index.html` 是页面入口，`app.js` 负责书目操作。通过本地静态服务打开；无账号、无外部 API。数据只保存在测试浏览器的 localStorage。
