# 魔搭线上部署

应用启动入口：`v3/public-demo.mjs`。创空间选择 Docker，服务监听 `0.0.0.0:7860`。

在平台设置非敏感环境变量 `PUBLIC_ORIGIN` 为实际分配的 HTTPS 应用域名（仅来源，不带路径或末尾斜线）。Dockerfile 已设置 `CLOUD_DEMO=1`，进入单对话框页面。

部署后验证 `/healthz`、首页、`/guide-video`、`/guide.mp4`、`/repair-case.json`，并实际执行一次故障版本检查，再切换正常版本复检。

线上使用三种固定阅读清单版本，浏览器在服务器执行，任务按访问者隔离。个人资料自动判断需下载代码并在本机配置模型连接。`/repair-case.json` 是已完成的独立修复对比，不冒充新访问者刚运行的结果。

当前仓库提供部署文件，不代表魔搭已部署成功；只有取得平台运行状态并验证公开网址后才填写参赛材料。
