## 本次脱敏规则

- 不复制个人复盘、原始对话、账户配置、提交身份信息、视频文件或视频制作材料。
- 删除任务标识、本机绝对路径、临时目录和非必要上下文；控制样例标题替换为通用名称。
- 保留预期/实际、断言结果、测试范围、重复次数与未知状态，不通过脱敏修改结论。
- 涉及其他真实项目的原始页面、素材、日志及个人材料不在本次公开范围；只采用受控案例和必要的机制记录。
- 未发布的原始文件及来源映射仍保留本地。部分公开内容为派生摘要，不能冒充完整原始证据。

本批仅增加资料，不修改产品运行代码或扩展其支持范围。当前迭代顺序仍为连续修复、同类迁移、真实收益，然后扩展一种相邻能力。
