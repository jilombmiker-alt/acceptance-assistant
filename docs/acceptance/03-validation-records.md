## 原始记录与公开派生版

公开 JSON 保留检查项、状态和必要证据值，删除任务标识、本机位置、非必要上下文。样例素材名称一致替换，不改变比较结果。部分记录只保留摘要字段，不能作为原始文件的逐字节副本。

原始文件和脱敏映射仅保留本地。公开派生记录可核对结论，但完整独立复现仍需执行测试并取得当次产物；记录完整性本身不证明判断正确。
